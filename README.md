# Personal Portfolio (v2)

My personal portfolio site, presenting selected projects and the services I offer. Built with **vanilla JavaScript** and **GSAP ScrollTrigger** for scroll-driven animation, and shipped as an installable **PWA**. The interface is Persian and right-to-left.

## What's inside

- About section, selected projects and a services overview (landing pages, corporate sites, online stores, PWAs, admin panels)
- Scroll-triggered animations with GSAP
- Web app manifest and service worker for installation and offline access
- Separate `index.html`, `styles.css` and `script.js`, no build step

## Run locally

```bash
npx serve .
```
